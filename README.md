## Why the light has to be safe, and what makes it safe

Nothing in this system can hide. The address *is* the content, so concealment
would require becoming something else — which changes the address. Three witnesses
in the same colour key locate anything, because three known points determine the
centre.

**But visibility alone is not safety.** A transparent system that can misrepresent
is more dangerous than an opaque one, because it gets believed. The second half has
to come from somewhere, and it comes from identities:

> **A constraint can be spoofed at the check. An identity has no check to spoof.**

